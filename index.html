The user picks Ubuntu, Debian or Alpine, as a web terminal or an XFCE desktop (noVNC). The machine destroys itself on expiry.

A single pipeline from packet to incident, for the lab, PCAP replay and live capture (scapy). 52 flow features, two machine-learning stages (anomalies learned on benign traffic only, then a classifier that names the family and can veto), a per-host threshold, and alerts grouped into incidents.   • Projet personnelPersonal project Preuve de concept de cybersécurité industrielle réalisée en octobre 2026 : une démonstration technique, pas un produit homologué. Tout tourne en local, sans service cloud, ce qui permet de l'attaquer sans risque pour un système réel. An industrial-cybersecurity proof of concept built in October 2026: a technical demonstration, not a certified product. Everything runs locally, with no cloud service, so it can be attacked with no risk to a real system.
  • Ce que ça simuleWhat it simulates La supervision d'une ligne de trempe de verre (norme EN 12150-1) : un automate en C11 pilote un four à quatre zones de chauffe, une passerelle lit ses mesures en lecture seule, une diode de données les transmet à sens unique à une API, puis à une console web qui affiche à chaque rôle ce qu'il a le droit de voir. The supervision of a glass-tempering line (EN 12150-1): a C11 PLC drives a four-zone furnace, a gateway reads its measurements read-only, a data diode sends them one way to an API, then to a web console that shows each role what it is allowed to see.
  • La diode de donnéesThe data diode Un émetteur UDP qui n'appelle jamais recv() : il n'existe aucune route de retour du système d'information vers l'automate. Les trames sont signées (Ed25519, SHA-256) et numérotées contre le rejeu. A UDP sender that never calls recv(): there is no return route from the information system to the PLC. Frames are signed (Ed25519, SHA-256) and numbered against replay.
  • Accès, données, traçabilitéAccess, data, traceability Six rôles ; contrôle par rôle (RBAC) puis règles contextuelles (ABAC) qui refusent tout par défaut, appliqués côté serveur.
